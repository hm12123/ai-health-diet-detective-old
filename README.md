# 남을 위한 AI — 템플릿

한 사람을 위한 웹 서비스를 만들어 공개 주소로 띄우는 틀입니다.
**설치할 것이 없습니다. 브라우저만 있으면 됩니다.**

주소는 `https://내프로젝트이름.pages.dev` 형태로 생깁니다.

---

## 만드는 순서 (처음 한 번, 약 15분)

### 1. 내 레포 만들기
이 레포 맨 위의 초록색 **Use this template → Create a new repository**.
이름은 영문 소문자와 하이픈으로. 공개(Public)로 두세요.

### 2. Cloudflare 에서 Pages 흐름으로 들어가기
1. [dash.cloudflare.com](https://dash.cloudflare.com) 가입 (무료, 카드 안 넣습니다)
2. **Workers 및 Pages → 애플리케이션 생성**
3. ⚠️ **화면 맨 아래 「Pages로 계속」을 누릅니다**

> 가운데 큰 **Continue with GitHub** 버튼을 누르면 Workers 흐름으로 갑니다.
> 그쪽은 이 템플릿과 구조가 달라서 작동하지 않습니다. 반드시 맨 아래 작은 링크로 가세요.

### 3. 레포 연결하고 배포
1. **기존 Git 리포지토리 가져오기 → 시작**
2. GitHub 계정을 연결하고 1번에서 만든 레포 선택 → **설정 시작**
3. ⚠️ **빌드 출력 디렉터리에 `public` 을 입력합니다** (비어 있으면 화면이 안 뜹니다)
4. **저장 및 배포**

1~2분 뒤 주소가 생깁니다. 바로 열어 보세요.

> **AI 바인딩은 따로 안 해도 됩니다.** `wrangler.toml` 에 적혀 있어서 Cloudflare 가
> 자동으로 붙입니다. 확인하려면 프로젝트 **설정 → 바인딩** 에 `Workers AI / AI` 가
> 있는지 보면 됩니다.

### 4. 내 서비스로 바꾸기
깃허브에서 **`functions/_config.js`** 를 열고 연필 아이콘을 누릅니다.
여섯 칸을 내 내용으로 바꾸고 **Commit changes**.

고칠 파일은 이 하나뿐입니다.

### 5. 확인하기
커밋하면 자동으로 다시 배포됩니다. 1~2분 뒤 내 주소에서 두 가지를 봅니다.

- 제대로 적어 넣으면 → 답이 나오는가
- **일부러 정보를 빼고 적으면 → 답하지 않고 되묻는가** (파란 「먼저 확인할 것」)

두 번째가 안 되면 `_config.js` 의 `멈춤` 칸을 더 구체적으로 적으세요.

- 가입할 때 카드를 넣지 않습니다. 도메인도 필요 없습니다.

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 화면이 안 뜨고 404 | 3번의 **빌드 출력 디렉터리**가 `public` 인지 |
| 흐름이 달라 보임 | 2번에서 **「Pages로 계속」**을 눌렀는지. Workers 흐름으로 갔으면 처음부터 |
| 답 대신 "지금은 답할 수 없습니다" | 오늘 한도를 넘었거나, `_config.js` 의 모델 이름이 틀렸거나 |
| 설정 → 바인딩에 AI 가 없음 | `wrangler.toml` 이 레포 맨 위에 있는지. 없으면 직접 추가(이름은 대문자 `AI`) 후 재배포 |
| 제목이 "준비 중" 그대로 | 배포가 아직 안 끝났습니다. 1~2분 뒤 새로고침 |
| 커밋했는데 화면이 그대로 | Cloudflare **배포** 탭에서 실패했는지 확인 |
| 정보를 빼도 되묻지 않음 | `_config.js` 의 `멈춤` 칸이 비었거나 추상적임 |
| 한국어가 어색함 | `모델` 을 `"@cf/meta/llama-3.1-8b-instruct"` 로 바꿔 보세요 |

문제를 자세히 보려면 주소 뒤에 `/api/ask?debug=1` 로 호출해 모델 원문을 확인할 수 있습니다.

## 구조

```
public/index.html        화면 (고칠 일 거의 없음)
functions/_config.js     ← 여기만 고칩니다
functions/api/ask.js     지시문을 만들어 AI 에 보냄 (JSON 스키마로 답/물음 구분)
functions/api/meta.js    화면 글자를 내보냄
AGENTS.md                사람과 AI가 같이 읽는 설명서
docs/                    인터뷰 기록 · 명세서 · 점검
wrangler.toml            Cloudflare 설정 + AI 바인딩 선언
```

API 키는 어디에도 없습니다. AI 는 Cloudflare 바인딩으로 부릅니다.
